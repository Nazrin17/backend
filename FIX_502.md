# 🔧 502 Bad Gateway - Database Migration Sorunu

502 hatası alıyorsun çünkü database migration'ları çalışmamış. Şu adımları takip et:

## Çözüm: Migration'ları Çalıştır

### Yöntem 1: Render Shell'den (Önerilen)

1. **Render Dashboard'a git:**
   - https://dashboard.render.com
   - `medico-backend` service'ini aç

2. **Shell'e git:**
   - Sol menüden "Shell" sekmesine tıkla
   - Veya sağ üstte "Shell" butonuna tıkla

3. **Migration çalıştır:**
   ```bash
   npm run prisma:deploy
   ```

4. **Seed data ekle (opsiyonel):**
   ```bash
   npm run seed
   ```

5. **Service'i restart et:**
   - "Manual Deploy" → "Deploy latest commit"

### Yöntem 2: Start Command Kontrolü

Start command şu şekilde olmalı:
```
npm run prisma:deploy && npm start
```

Render dashboard'da kontrol et:
1. Settings → Start Command
2. Yukarıdaki komutun olduğundan emin ol
3. Değilse, düzelt ve kaydet
4. Manual deploy yap

### Yöntem 3: Migration Dosyası Oluştur

Eğer migration dosyası yoksa:

1. **Local'de migration oluştur** (Node.js kuruluysa):
   ```bash
   npm run prisma:migrate
   ```

2. **Commit ve push et:**
   ```bash
   git add prisma/migrations
   git commit -m "chore: add initial migration"
   git push
   ```

3. **Render'da deploy et**

## Kontrol Listesi

- ✅ Database bağlantısı çalışıyor mu? (Render dashboard → Database → "Connections")
- ✅ Migration'lar çalıştı mı? (Shell'den kontrol et)
- ✅ Start command doğru mu? (`npm run prisma:deploy && npm start`)
